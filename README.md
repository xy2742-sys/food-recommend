# What's for Dinner?

An interactive recipe discovery page for anyone looking for fresh meal ideas. Choose a food preference, then explore recipes from around the world.

My idea is designed for those who wish to have better dietary choices or are struggling with what to eat every day. When someone clicks the button, the system will randomly recommend various types of recipes from around the world. If you are not satisfied, you can click a second time.

I wanted the AI to recommend food from all over the world for me. It did a great job and even gave some emojis to make this webpage look less boring. However, it wasn't set up for everyone to understand. Since I spoke Chinese to him, the AI created a Chinese web page for me.
I asked him to increase the language options for the web page so that everyone can switch to English more conveniently for understanding. Artificial intelligence can quickly help me write good code and link it to GitHub. I need to test the user experience of the web page to make users like to use it and make it convenient to use. At present, I'm quite satisfied with this webpage because some of the types it recommends are ones I haven't tried yet, but for others, it might be a bit limited. Maybe I can ask the AI to add more, or I should give it a list.

## Features

- Discover a random recipe and shuffle for another idea
- Filter recipes by light meals, high protein, under 30 minutes, or vegetarian options
- Switch between Chinese and English; your language choice is saved in the browser
- View each recipe's description, cooking time, estimated calories, and tags
- Responsive layout for desktop and mobile screens

## Run locally

Open `index.html` in a web browser. No installation or build step is required.

## Project files

- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — recipe data, language translations, and interactions
